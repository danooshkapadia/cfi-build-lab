# CFI Build Lab · field guide

Publish in about three minutes:

1. github.com/new → name it `cfi-build-lab` → Public → Create repository.
2. On the empty-repo page click "uploading an existing file". Drag the whole contents of this folder in (index.html, facilitator.html, the img and downloads folders, this README). Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch: main, folder: / (root) → Save.
4. In about a minute the guide is live at https://danooshkapadia.github.io/cfi-build-lab/
   Facilitator page: https://danooshkapadia.github.io/cfi-build-lab/facilitator.html

Press F on the field guide to show or hide your cues. Arrow keys move between sections.
